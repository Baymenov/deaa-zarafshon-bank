# DEAA Case Study: Zarafshon Bank Data Platform

Data Engineering and Advanced Analytics, Level 6.

## Author

Nurbek Baymenov (individual submission)

## About

This repository contains my solution to the Zarafshon Bank case study. Zarafshon Bank is a fictional commercial bank in Uzbekistan. The task is to design one analytics platform that replaces four separate reporting tools. This is a design exercise, so there is no running system. The solution consists of a written report and SQL queries.

## Structure

- report/ : the final PDF report (Group_Surname_DEAA_Bank.pdf)
- sql/ : SQL queries and table definitions, one file per part
- diagrams/ : schema and pipeline diagrams used in the report

## Parts

1. Dimensional model for transactions and balances
2. Customer history and slowly changing dimensions
3. Loan lifecycle (accumulating snapshot)
4. Data vault for four customer sources
5. Pipeline, data quality and compliance

## Notes

All figures in the case are invented for teaching. Where the scenario leaves something undefined, the report states an assumption.
